## EcoScan AI 🌱

EcoScan AI helps users identify waste materials using AI and promotes eco-friendly disposal by rewarding eco points.

### Features
- AI-based waste scanning
- User authentication (JWT)
- Eco points & scan history
- Leaderboard-ready architecture
- Password recovery with OTP

### Tech Stack
- Frontend: HTML, CSS, JavaScript
- Backend: Node.js, Express
- Database: MongoDB Atlas
- AI: Gemini Vision API

### How to run
1. Clone repo
2. Add .env
3. npm install
4. node server.js
